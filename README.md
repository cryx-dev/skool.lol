# 🎓 skool.fun

> **For Students. By Students.** Making school more bearable, one function at a time.

---

## ✨ What is skool.fun?

**skool.fun** is a student-created platform designed to help students navigate school, share resources, and connect with each other. Built with pure JavaScript, HTML, and CSS—because sometimes the best solutions are the simplest ones.

Whether you're looking to unblock resources, find study tips, or just need a break from the school grind, skool.fun has got you covered.

---

## 🚀 Features

- 🔓 **Unblocked Access** - Access what you need, when you need it
- 🤝 **Student Community** - Connect with students from your school
- 📚 **Resource Hub** - Share and discover study materials
- ⚡ **Fast & Lightweight** - Built with vanilla JS for maximum speed
- 🎨 **Clean Design** - Intuitive interface designed by students, for students

---

## 🛠️ Tech Stack

- **JavaScript** - 96.7% - The backbone of skool.fun
- **HTML** - 2.9% - Semantic structure
- **CSS** - 0.4% - Minimal, efficient styling

## 📖 Getting Started

### Prerequisites
- A web browser (any modern browser works!)
- An internet connection

### Installation

1. Clone the repository:
```bash
git clone https://github.com/cryx-dev/skool.fun.git
cd skool.fun
```

2. Open `index.html` in your browser:
```bash
open index.html
# or just double-click the file
```

That's it! No build process, no dependencies. Just pure web magic.
