# Contributing to skool.lol

Thank you for your interest in contributing to **skool.lol**! We're building tools to make school more bearable, one function at a time. Whether you're a student, developer, or just passionate about education, your contributions are welcome.

## Getting Started

1. **Fork the Repository**: Click the "Fork" button on GitHub to create your own copy.
2. **Clone Your Fork**: 
   ```bash
   git clone https://github.com/YOUR_USERNAME/skool.lol.git
   cd skool.lol
   ```
3. **Create a Branch**: 
   ```bash
   git checkout -b feature/your-feature-name
   ```

## How to Contribute

### Reporting Bugs
- Check if the issue already exists in the [Issues](https://github.com/cryx-dev/skool.lol/issues) section.
- Provide a clear, descriptive title and detailed description of the bug.
- Include steps to reproduce and any relevant error messages or screenshots.

### Suggesting Features
- Open an issue with the title prefix `[FEATURE REQUEST]`.
- Clearly describe the feature and why it would benefit students.
- Include any relevant examples or use cases.

### Submitting Code
1. **Follow the Code Style**: 
   - Keep it clean and readable
   - Add comments for complex logic
   - Follow existing naming conventions

2. **Test Your Changes**: 
   - Test locally before submitting a pull request
   - Ensure your changes don't break existing functionality

3. **Commit Messages**: 
   - Use clear, descriptive commit messages
   - Example: `feat: add grade calculator feature` or `fix: resolve styling issue on mobile`

4. **Pull Request Process**:
   - Push your branch to your fork
   - Open a pull request with a clear title and description
   - Link any related issues (e.g., "Closes #42")
   - Wait for review and be open to feedback

## Getting Help

- Check existing issues and discussions for answers

## Code of Conduct

- Be respectful and inclusive
- Help fellow contributors
- Focus on the goal: making school more bearable for students
- No spam or promotional content
