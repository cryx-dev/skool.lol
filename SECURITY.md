# Security Policy

## Reporting Security Vulnerabilities

At skool.lol, we take security seriously. If you discover a security vulnerability, please report it responsibly by following these steps:

### How to Report

1. **Do not** create a public GitHub issue for security vulnerabilities
2. **Email us** at security@skool.lol with:
   - A clear description of the vulnerability
   - Steps to reproduce (if applicable)
   - Potential impact
   - Suggested fix (if you have one)

3. **Include**:
   - Your name and contact information
   - Affected version(s) of skool.lol
   - Your GitHub username (optional)

### Response Timeline

We commit to:
- **Acknowledge** receipt of your report within 48 hours
- **Investigate** and validate the issue promptly
- **Communicate** progress updates with you
- **Release** a fix as soon as possible

## Security Best Practices for Users

### Protecting Your Account
- ✅ Use a strong, unique password
- ✅ Enable two-factor authentication (2FA) where available
- ✅ Keep your browser and extensions updated
- ✅ Be cautious with shared school computers

### Using skool.lol Safely
- ❌ Don't share personal information more than necessary
- ❌ Don't share login credentials with anyone
- ❌ Don't trust links from untrusted sources
- ✅ Report suspicious activity to us immediately

### For Students
- 🎓 Always follow your school's acceptable use policies
- 🎓 Use skool.lol responsibly and ethically
- 🎓 Respect other users' privacy and data
- 🎓 Report any abuse or inappropriate content

## Security in Our Code

### What We're Doing
