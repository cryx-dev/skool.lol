# Frequently Asked Questions (FAQ)

## General Questions

### What is skool.lol?
**skool.lol** is a student-created platform designed to make school life easier. We provide tools, resources, and a community built **by students, for students** — with no corporate bloat, just pure functionality.

### Who can use skool.lol?
Anyone! Though skool.lol is built with students in mind, teachers, parents, and anyone interested in educational resources can use it.

### Is skool.lol free?
Yes! skool.lol is completely free to use. We believe educational tools should be accessible to everyone.

### How is skool.lol licensed?
skool.lol is licensed under the **MIT License**. This means you can use, modify, and distribute the code freely under the license terms. See [LICENSE](LICENSE) for details.

## Features & Usage

### What features does skool.lol have?
Currently, skool.lol provides:
- 📚 Resource discovery and sharing
- 🤝 Student community connections
- ⚡ Lightning-fast performance
- 🎨 Beautiful, intuitive design
- 🔒 Privacy-focused approach

### How do I get started?
1. Visit [skool-lol.vercel.app](https://skool-lol.vercel.app/)
2. Explore the available resources and features
3. Join the community if you'd like to contribute or connect with other students

### Can I use skool.lol on my phone?
Yes! skool.lol is designed to work on all devices — phones, tablets, and computers.

### Is skool.lol available offline?
Currently, no. skool.lol requires an internet connection to access resources and the community.

## Technical Questions

### What technology does skool.lol use?
- **Frontend**: HTML, CSS, JavaScript
- **Deployment**: Vercel (and other static hosts)
- **No dependencies**: We keep it lean and fast

### Can I run skool.lol locally?
Yes! It's super easy:
```bash
git clone https://github.com/cryx-dev/skool.lol.git
cd skool.lol
python3 -m http.server 8000
# Visit http://localhost:8000
```

See [Quick Start](README.md#-quick-start) in the README for more options.

### Can I deploy skool.lol myself?
Yes! We provide one-click deployment buttons for:
- [Netlify](https://app.netlify.com/start/deploy?repository=https://github.com/cryx-dev/skool.lol)
- [Vercel](https://vercel.com/import/project?template=https://github.com/cryx-dev/skool.lol)
- [Render](https://render.com/deploy?repo=https://github.com/cryx-dev/skool.lol)
- [Railway](https://railway.app/new/template?template=https://github.com/cryx-dev/skool.lol)

### Why doesn't skool.lol use GitHub Pages?
GitHub Pages has limitations for this project's architecture. We use Vercel and other modern static hosts for better performance and features.

## Troubleshooting

### The site isn't loading. What do I do?
1. Check your internet connection
2. Try refreshing the page (Cmd+R or Ctrl+R)
3. Clear your browser cache
4. Try a different browser
5. Report the issue on [GitHub Issues](https://github.com/cryx-dev/skool.lol/issues)

### A feature isn't working. What should I do?
1. Check if it's a known issue: [GitHub Issues](https://github.com/cryx-dev/skool.lol/issues)
2. Provide details:
   - What browser and device you're using
   - Steps to reproduce the problem
   - Any error messages you see
3. Open a new issue with this information

### The website is slow. How can I help?
This helps us improve! Please report:
- What part of the site is slow
- Your device and connection type
- Browser and version
- Open an issue with details
